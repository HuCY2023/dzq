## 2. 位置是怎么判的

股价 = 资产侧 × 资金侧。泡沫越往后，资金侧越压过资产侧：财报很好，股价照样跌。

A 股仍是融资市。作者给的数量级（近十年，未当作精确常数）：

- 每年主力净流出大约 **5 万亿**（约一个月均 **4000 亿**）
- 每年解禁大约 **3 万亿**，大于 IPO/增发那几千亿；解禁后两三个月，主力流出容易高于月均
- 市场要涨，需要把这 5 万亿对冲掉之后还有净流入。近三年每年市值增加大约 7–8 万亿，剩下约 1–2 万亿净流入

三种要管的系统性流动性风险：

1. **杀杠杆**（融资余额掉下去，而且不修复）
2. **股东退出**（主力净流出 + 解禁高峰）
3. **国家队退出 / 过热调控**（汇金、证金，或宽基 ETF 净流出）

三资金共振：

| 三者方向 | 市场 |
|----------|------|
| 一起流入 | 强涨 |
| 一起撤出 | 强跌 |
| 方向不一致 | 震荡 |

行为金融走到极值，只说明市场分裂、买盘吃力。真正触发下跌的，仍是资金侧的边际变差。6 月第四周的例子：日常分数大约在 **+2 到 −2**，那一周因为多项同时变差，打到 **−9**。

国家队是双向的：过热时降温，下跌时托举。立场是慢牛，不是疯牛。杀杠杆已经形成时，国家队流入往往只能把下跌减速，不能代替融资余额来判断跌完没有。

## 3. 指标分层（五项只是第一层）

### A. 资金三件套（指南针主体）

| 指标 | 作者口径 | 偏离怎么读 | 我们现在 |
|------|----------|------------|----------|
| 主力净额 | 超大单+大单。代表大股东/财务投资者的方向，**不是股东身份证明** | 月均约 −4000；周均约 −1000；日均约 −200。周净流出 ≥2000 一年大约三五次，之后常转弱；≥3000 更极端。月流出到 8000 或万亿是均值的两倍。**只作风控，不作看多风向标**：偶发净流入常是为了之后更大的流出 | 东财日频，库内目前只有 1 天，长历史缺失 |
| 国家队 | 汇金+证金余额的月变动。披露晚，可用宽基 ETF 净流入代替 | 过热月份高额净流出 = 降温；下跌时净流入 = 托举 | 只有宽基 ETF **份额**，还不是汇金/证金月变动，也不等于 ETF 净流入 |
| 杠杆 | 融资余额（融券很小，两融余额接近） | 月变动 ±500 正常；\|月变动\| ≥1000 为大幅偏离。分位到顶端后回落 = 边际变差。持续下降 = 跌势未结束。场内杠杆会失真，场外杠杆看不见 | 沪深融资余额已入库，含全样本分位 |

打分方式（片子上能看见的）：单指标常见 **+1 / −2** 这种档，不是连续公式。多项同时为负才把分数打出日常区间。

### B. 行为两件套（极值与背离）

| 指标 | 怎么读 | 我们现在 |
|------|--------|----------|
| 成长–价值偏离 | 创业板/科创相对价值。走到约 **17**，或历史分位 90%–100% 后回落，表示资金从成长切向价值。收窄时跟着切，比死守价值或死守成长更符合这套框架 | 乐咕创业板50 / 上证50，`(PE比+PB比)/2`，序列偏稀 |
| 52 周新高−新低 | 偏多时常约 10∶1；偏空时常约 1∶10。指数还在涨、比值已经 1∶10，是分裂背离。2026-06-29 的例子：新高约 190、新低约 2300 | 主图用 K 线湖约 252 日，未剔 ST，不是作者样本 |

### C. 提前量

| 指标 | 怎么读 | 我们现在 |
|------|--------|----------|
| 解禁金额 | 提前大约一年能看到月/周安排。解禁不等于当天卖出，但之后两三个月主力流出容易偏高。年规模约 3 万亿 | 东财实际解禁市值，月/季，全市场柱 + 科创板线 |

### D. −9 周扩展项 + 外盘旁证（已进诊断分层）

GUI / PDF 报告按 **A→E 分层**展示（`diagnosis.layers`）。有数才进合计分，空值不记 0。

| 指标 | 作者用法 | 系统状态 |
|------|----------|----------|
| 公募新发规模 | 上周 ≥300 亿份且本周不到一半 → −1 | 入库 `fund_issue` · `score_fund_issue` |
| 大股东减持 | 本周 ≥50 亿且比上周多 75% → −1 | 入库 `holder_reduce` · `score_holder_reduce` |
| 行业资金切换 | 科技周 ≤ −80 且银行 ≥ −10 → −1 | 入库 `industry_flow_daily`（窗约 120 日） |
| 散户剪刀差 | 周「主力−(中+小)」≤ −3000 → −1 | 依赖主力日频含中小单列 |
| 成交拥挤度 | 例：约 62.8% 成交在前 10% 个股 | **占位 gap**（湖集中度未上线） |
| 隐含波动率 | 科创50 分位 ≫ 标普 VIX + 高杠杆 | **占位 gap** |
| 全球杠杆 | 美股保证金/M2≈6% | `us_crowding` 旁证，默认不进 A 股合计分 |
| 二阶导 | 拥挤资产涨价斜率减速；财报前高低切 | 产业价，不进行情库（报告只写 K 型提示） |
| 外盘相关 | 顶/破时 A↔SOX/KOSPI 相关升高 | 未联动；红灯「外盘脆弱」用拥挤评分代理 |

**红灯四件套**（报告单独一块）：偏离极值 · 高低比背离 · 高杠杆 · 外盘脆弱。亮灯≠自动离场；扳机仍是资金侧边际。

明确不拿来当领先指标：散户新开户（次月才公布，而且是反指）、中单小单单独、换手率、银证转账、主力净流入单日脉冲。

## 4. 位置语言（诊断要落到这几句话）

按证据强弱，页面只说其中一句，并列出依据和缺口：

1. **杀杠杆进行中**：融资余额月变动大约 ≤ −1000 亿，或分位从顶端连续回落且尚未修复。
2. **红灯：行为已极值，资金侧在变差**：偏离接近 17，或新高/新低严重偏空；同时杠杆降速、解禁偏高，或主力周流出 ≥2000（有数时）。
3. **杠杆肥尾**：融资月变动大约 ≥ +1000，偏离仍高。这是泡沫自我加强，机会和脆弱在一起。
4. **偏离收窄**：偏离从高位往下走。资金从成长切价值，宜顺风，不宜教条站队。
5. **过热**：新高远多于新低，杠杆仍在加。国家队若退出，是降温而不是趋势确认。
6. **震荡 / 证据不够**：三资金方向凑不齐，或主力、国家队还没有可评分的长序列。

作者那一周的 −9，用了主力、宽基 ETF、杠杆、散户剪刀差、公募新发、减持、行业资金。我们缺的项不记 0 分，避免把「没数据」说成「没风险」。

## 5. 资金行为图上的仓位带

图：`research/DP/资金行为.jpg`。从左到右是一轮涨跌。黑字是上涨段谁在买，红字是下跌段谁在卖。郭嘉队按国家队理解。

| 顺序 | 主导 | 颜色 | 仓位带 | 配置 |
|------|------|------|--------|------|
| 启动 | 国家队 | 黑 | 60–80% | 宽基，不追已经很热的成长 |
| 推进 | 融资 | 黑 | 60–70% | 杠杆还在加，可以留仓，波动会变大 |
| 机构参与 | 保险·ETF·公募 | 黑 | 60–70% | 机构和宽基一起买 |
| 过热 | 散户 | 黑、后段 | 40–50% | 散户是反指，不追 |
| 顶部降温 | 国家队 | 红 | 30–40% | 国家队在卖，减仓 |
| 杀杠杆 | 融资 | 红 | 20–30% | 只留底仓，等融资余额止跌 |
| 切向价值 | 保险·ETF·公募 | 红 | 30–40% | 偏离收窄，少成长、多价值 |
| 散户离场 | 散户 | 红 | 20–30% | 常靠近一段低点，杠杆没止住之前不加 |

当前诊断会落到其中一段。历史时期只在有直接序列时写名字：融资余额对应图上的融资段，偏离收窄对应保险/ETF/公募切向价值。国家队和散户没有月度序列，不把广度或杠杆填成这两个名字。

**与 §6 的关系**：上表是资金行为图上的阶段仓位。产品首屏的**散户决策仓位带以 §6 为准**（例如顶部郭嘉队卖 → 决策「离场」0–20%，比上表 30–40% 更狠）。仓位是风险带，不是下单指令。

## 6. 散户视角：指标 → 投资决策（本系统要落地的结论）

你是散户。其他几路资金口头讲价值投资，行为上高抛低吸：低位恐吓让你走，高位唱多让你接。  
本系统不解释每一根 K 线，只做一件事：**盯其他几路资金行为有没有重大改变，尽快打出决策分，并落到仓位动作。**

### 6.1 资金行为图在说什么（`资金行为.jpg`）

从左到右一轮涨跌。黑字=上涨段谁在买，红字=下跌段谁在卖。

| 阶段 | 谁在动 | 散户该怎么想 |
|------|--------|----------------|
| 底部启动 | 郭嘉队买 | 他们敢买，才考虑抄底/加仓；别听恐吓离场 |
| 推进 | 融资加 | 趋势里可留仓；看融资**分位**，不是只看增减 |
| 机构参与 | 保险·ETF·公募买 | 顺风可以，不追已经很热的成长 |
| 过热 | 散户接盘 | **你自己就是反指**；别人唱多时减仓/不追 |
| 顶部 | 郭嘉队卖 | **最高优先离场信号**；别接盘 |
| 下跌 | 融资杀杠杆 → 机构走 → 散户最后砍 | 余额高位还在掉就别抄；低位企稳再谈跟随 |

### 6.2 指标怎么指向动作

| 指标 | 重大改变长什么样 | 散户动作 |
|------|------------------|----------|
| 郭嘉队ETF（最高优先） | 高仓位分位还在减 | **离场 / 重减** |
| 郭嘉队ETF | 低仓位分位还在加 | **抄底 / 加仓**（宽基，不追热点） |
| 融资 | 高分位还在加 | **警惕离开**（高位唱多接盘段） |
| 融资 | 高分位去杠杆 | **减仓底仓**，等止住 |
| 融资 | 低分位增减 | **跟随**，不是高位那套反着做 |
| 主力 | 周极端流出 | 风控减仓，不作看多 |
| 偏离 / 广度 | 极值 + 资金侧变差 | 红灯，先减 |
| 解禁 | 高峰 | 之后两三个月更易流出，仓位偏保守 |

### 6.3 打分 → 五档决策（页面首屏只亮一档）

合计分由有数的项加减（缺的不记 0）。决策优先看**硬信号**（郭嘉队高位减、融资高位加），再看分数带：

| 决策 | 典型触发 | 仓位带 |
|------|----------|--------|
| **离场** | 郭嘉队高位减；或分数 ≤ −4 | 0–20% |
| **减仓** | 融资高位加/杀；国家队高位拥挤；分数 ≤ −2 | 20–40% |
| **持有观望** | 证据打架或分数约 −1～+1 | 40–55% |
| **加仓** | 融资低位跟随且分数 ≥ +2；无离场硬信号 | 60–70% |
| **抄底** | 郭嘉队低位加 + 融资低位；分数偏正 | 60–80% |

仓位带是风险配比，不是下单指令。第一目标是：**别在别人高位退出时还在接盘。**
