## 2. 核心指标：保证金债务 / M2

## 3. 新增指标说明

### Shiller CAPE（席勒周期调整市盈率）

- 诺贝尔奖得主 Robert Shiller 设计，用过去 10 年经通胀调整的平均盈利计算
- 长期均值 ~17x，历史峰值 44.2x（1999年12月科网泡沫顶）
- 当前 30.8x → 94.7% 历史分位 → 估值极高但未破纪录
- 数据源：Yale 大学 XLS `http://www.econ.yale.edu/~shiller/data/ie_data.xls`

### VIX 期限结构（VIX/VXV）

- VIX = 1月隐含波动率，VXV = 3月隐含波动率
- VIX/VXV > 1 = **backwardation**（近期恐慌高于远期 → 恐慌预期）
- VIX/VXV < 1 = **contango**（正常状态）
- 数据源：FRED CSV `VIXCLS` + `VXVCLS`

### HY-IG 信用利差

- HY (高收益债) 利差 - IG (投资级债) 利差 = 信用风险溢价
- 利差走阔 → 市场开始定价信用风险 → 通常领先股市转折
- 当前 2.25% 处于 2014 年以来 89.4% 分位 → 信用压力偏高
- 数据源：FRED CSV `BAMLH0A0HYM2` + `BAMLC0A4CBBB`

### 美联储流动性

- 美联储总资产 (WALCL) → 衡量缩表/扩表速度
- 逆回购 (RRPONTSYD) → 过剩流动性指标，接近 0 表示流动性"蓄水池"枯竭
- 净流动性 ≈ Fed 资产 - TGA - ON RRP
- 数据源：FRED CSV `WALCL` + `RRPONTSYD`

## 4. 综合拥挤度评分

| 评分 | 含义 |
|------|------|
| 0 | 正常：未触发预警 |
| 1 | 微热：一项指标预警 |
| 2 | 偏热：两项指标预警 |
| 3 | 高度拥挤：多项指标预警 |
| 5+ | 极度拥挤：历史级风险 |

- CAPE < 35（未到极端）

## 6. 与 A 股诊断的关系

美股拥挤度作为**扩展参考位**加入 `diagnose_position()`：
- **不计入 A 股打分**（避免跨市场混淆）
- 但当保证金/M2 ≥ 6% 且 VIX 高企时，提示全球系统性风险
- 大周期原文："泡沫在疯涨的阶段和破裂的阶段，全球股市的相关度会陡增"
